# 🎓 Placement Prep

A College Placement Preparation Platform designed to help students prepare for campus placements.

## 🚀 Features

- 🧠 Aptitude Practice
- 💻 Coding Practice
- 📝 Mock Tests
- 🎤 Interview Preparation
- 📊 Progress Dashboard
- 🏆 Leaderboard
- 🔐 User Login & Signup

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- MySQL
- Git & GitHub

## 📌 Project Overview

Placement Prep provides students with a simple platform to practice aptitude, coding, mock tests, and interview questions while tracking their preparation progress.
